МетеоUA | Офіційний бот

Бот українською мовою для каналу та спільноти «МетеоUA». Він показує поточну погоду, прогнози, офіційні попередження, приймає репорти користувачів на модерацію, створює звернення та допомагає модераторам керувати групою.

Підключення Telegram токена:
1) Отримайте токен у @BotFather.
2) Додайте його в environment variable TELEGRAM_BOT_TOKEN.
3) Запустіть один Node.js сервіс командою npm start.

Бот читає тільки TELEGRAM_BOT_TOKEN для запуску Telegram transport. Якщо токен відсутній, старт зупиниться з коротким зрозумілим повідомленням. Логи показують лише безпечні ознаки наявності змінних, наприклад TELEGRAM_BOT_TOKEN set: true, і ніколи не друкують сам токен, ключі, Authorization headers або MongoDB credentials.

Команди:
/start — відкриває головне меню з кнопками Погода, Прогноз, Попередження, Новини, Репорт і Допомога. Параметри не потрібні.
/weather — показує поточну погоду для збереженого міста. Можна вказати місто: /weather Київ.
/forecast — відкриває меню прогнозу: сьогодні, завтра, 7 днів, усі області. Використовує збережене місто або DEFAULT_CITY.
/alerts — показує активні офіційні попередження з UKRHYDROMET_ALERTS_URL. Якщо джерело не налаштовано, відповідає дружнім українським повідомленням.
/news — показує останні погодні новини з WEATHER_NEWS_RSS_URL. Якщо RSS не налаштовано, відповідає дружнім українським повідомленням.
/report — приймає текст і/або фото погодної події на модерацію. Репорти ніколи не публікуються автоматично.
/ticket — створює звернення до команди МетеоUA. Копія надсилається в TELEGRAM_MOD_CHAT_ID тільки якщо він налаштований.
/moderation — показує меню модерації.
/help — показує довідку.
/reset — очищує AI памʼять для поточного чату.
/warn — видати попередження через reply.
/strictwarn — видати суворе попередження через reply.
/warnings — показати активні попередження користувача через reply.
/removewarn — зняти попередження за ID.
/mute — обмежити користувача через reply.
/unmute — зняти обмеження через reply.
/kick — видалити користувача з групи через reply.
/ban — заблокувати користувача через reply.
/unban — розблокувати користувача через reply.
/delete — видалити повідомлення через reply.
/purge — видалити останні повідомлення.
/lock — увімкнути блокування, наприклад /lock links.
/unlock — вимкнути блокування, наприклад /unlock links.
/modlog — показати останні дії модерації.

Environment variables:
TELEGRAM_BOT_TOKEN — обовʼязковий токен Telegram бота з BotFather.
TELEGRAM_MOD_CHAT_ID — optional чат модерації для копій репортів і тикетів.
TELEGRAM_OWNER_ID — optional Telegram ID власника або список ID через кому для модераційного доступу.
DEFAULT_CITY — optional місто за замовчуванням. Якщо не задано, використовується Київ.
UKRHYDROMET_ALERTS_URL — optional URL офіційного JSON-джерела попереджень УкрГМЦ.
WEATHER_NEWS_RSS_URL — optional RSS-стрічка погодних новин.
MONGODB_URI — optional MongoDB для користувачів, попереджень, тикетів, репортів, кешу погоди, журналів і AI памʼяті. Якщо не задано, бот працює з обмеженим in-memory fallback.
COOKMYBOTS_AI_ENDPOINT — optional базовий URL CookMyBots AI Gateway. Код сам додає /chat.
COOKMYBOTS_AI_KEY — optional ключ CookMyBots AI Gateway. Якщо не задано, AI-відповіді будуть недоступні, але бот продовжить працювати.

Погодні дані беруться з Open-Meteo. Офіційні попередження читаються тільки з налаштованого джерела УкрГМЦ. AI не використовується як джерело температури, прогнозів, попереджень або фактів.

MongoDB notes:
Бот зберігає довгострокову памʼять у memory_messages, репорти в reports, тикети в tickets, попередження в warnings, модераційні дії в moderationActions, кеш погоди в weatherCache, налаштування в settings і публікації в publications. Якщо MongoDB недоступна, помилки підключення та критичні read/write операції логуються без секретів.
